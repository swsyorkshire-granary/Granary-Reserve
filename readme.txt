GRANARY RESERVE — iPhone/iPad web app package

This folder is ready to publish as a web app/PWA.

Files:
- index.html — the app
- manifest.webmanifest — Home Screen app settings
- sw.js — offline/app caching

After it is hosted at an https:// address:
1. Open the address in Safari on iPhone/iPad.
2. Tap Share.
3. Choose Add to Home Screen.
4. Open Granary Reserve from the new Home Screen icon.

The current starter collection is embedded in the app.
Data added in the app is stored locally in the browser on each device.
For true iPhone/iPad synchronisation, the next stage is a cloud database/sync layer.
